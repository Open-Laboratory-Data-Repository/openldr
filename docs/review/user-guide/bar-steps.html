1.Add a widget

Open the dashboard's dots menu again and select Add widget.

2.Name the widget

In the title field at the top left of the editor, enter Orders by test.

3.Count test orders

Keep Data on Test Orders and Summarize on Count.

4.Group the orders by test

Select Group by, the second icon button below Summarize.

In the new Group by list, choose Test.

5.Choose a bar chart

Open the widget editor's dots menu and select Charts.

In Visualization Type, select Bar.

6.Save the widget

Open the editor's dots menu again and select Save.

7.Check your chart

Find Orders by test on the dashboard. New widgets appear at the bottom.
