Start here

OpenLDR Studio is the browser app for your lab's records. Open it to use dashboards, reports and forms.

Start by getting access to Studio. If another guide asks you to run a command, use the CLI walkthrough below first. You do not need sample data to follow this page.

Open Studio

Get the Studio address and an account from your administrator. Open that address in your browser, then sign in.

You can use Studio from another computer or a phone. If your organisation requires Tailscale or a VPN, connect before opening the address.

Once you have signed in, continue with the Dashboard guide, or read on if you need the command line.

Use the command line

The command-line interface, or CLI, runs OpenLDR tasks from typed commands. You enter them in a terminal window.

Operators use the CLI to import files and maintain an installation. Each guide explains when you need it.

In this walkthrough, you will open a terminal and ask OpenLDR for help. These help commands do not import or change records.

Before you begin

You need access to the computer hosting OpenLDR and the folder where it was installed. The installed CLI uses Docker, so Docker and OpenLDR must be running. Your account must have permission to use Docker.

If you only have browser access, ask your administrator to run the command for you.

I am connecting to a remote server

Opening Studio through Tailscale gives you access to the browser app. To run commands on its server, ask your administrator for terminal access.

They may provide an SSH connection. SSH opens a secure terminal session on another computer. Use their connection instructions. A connection command can look like:

ssh username@server-address

Replace username and server-address with the details you received. After connecting, follow the steps for the server's operating system.

1.Open a terminal

Open a terminal on the computer hosting OpenLDR. If you connected through SSH, you are already in its terminal.

Windows
Open Start, search for PowerShell, then open Windows PowerShell.
macOS
Open Applications, then Utilities, then Terminal.
Linux
Open your applications menu and search for Terminal.

Type each command and press Enter. Copy only the command. Leave out prompt symbols such as $ or >.

2.Go to the installation folder

Ask the person who installed OpenLDR for this folder's location. Replace the example path below with that location. Keep the quotation marks if the path contains spaces.

cd changes the folder your terminal is using.

Linux or macOS
cd "/path/to/openldr"
ls

ls lists the files in that folder.

Windows PowerShell
cd "C:\path\to\openldr"
Get-ChildItem

Get-ChildItem lists the files in that folder.

Check before continuing

The folder should contain docker-compose.yml, a data folder, and either openldr or openldr.ps1. If these are missing, check the folder with your administrator.

3.Ask OpenLDR for help

Run the command for your operating system from the same terminal.

Linux or macOS
./openldr --help

./openldr runs the OpenLDR command file in the current folder.

Windows PowerShell
.\openldr.ps1 --help

.\openldr.ps1 runs the Windows command file in the current folder.

Expected result

The terminal shows this usage line, followed by options and a list of commands:

Usage: openldr [options] [command]

When the prompt returns, you can type the next command.

4.Read help for a specific command

Use ingest --help to see what the file-import command accepts. This displays instructions without importing anything.

Linux or macOS
./openldr ingest --help
Windows PowerShell
.\openldr.ps1 ingest --help

Expected result

Usage: openldr ingest [options] <file>

<file> is a required file path. Options in square brackets are optional. Neither set of brackets belongs in the command you type.

I run OpenLDR from a source checkout

Use the repository folder and the project's pnpm openldr command. This assumes the development dependencies are installed.

cd "/path/to/openldr_ce"
pnpm openldr --help
pnpm openldr ingest --help

In later guides, replace the ./openldr prefix with pnpm openldr. File paths refer to the computer running this command.

Understand commands and file paths

Before you import a file, check what each part of the command means. This example uses a placeholder filename:

./openldr ingest data/my-file.json
./openldr
Starts the installed CLI.
ingest
Imports a file into OpenLDR.
data/my-file.json
The file to import. Replace it with the path to your actual file.

For a Docker installation, put the file in the installation's data folder. For example:

openldr/
  docker-compose.yml
  openldr
  data/
    my-file.json

On Windows, the command file is openldr.ps1. Keep the data/ prefix when supplying the file path:

.\openldr.ps1 ingest data/my-file.json

The installed CLI runs inside OpenLDR's API container. The data folder is shared with that container. This lets the command read files you place there.

If OpenLDR is on a remote server, place the file in that server's installation folder. Saving it on your laptop does not put it on the server.

For commands that write files, use an output path under data/ too. Put quotation marks around a path containing spaces, such as "data/my file.json".

Each task's guide explains which file format and command options to use. The example above explains the path only. Running an import command writes records.

Use Studio on a phone

Use the same Studio address and account on your phone. Connect to your organisation's VPN first if required.

The main menu starts folded to leave room for the page. Here is how to switch pages.

1.Open the main menu

Select the menu button at the top left.

2.Choose a page

Select the page you want. The menu closes after you choose it.

If you get stuck

I cannot open Studio

Check the address your administrator supplied. If the installation requires Tailscale or a VPN, check that you are connected. If the page still does not open, give your administrator the address and the error you see.

The OpenLDR command cannot be found

Repeat step 2 and check that the command file is listed. Use ./openldr on Linux or macOS, or .\openldr.ps1 in PowerShell. Running openldr by itself does not select the file in your current folder.

The CLI cannot connect to Docker

Ask your administrator to check that Docker and the OpenLDR installation are running. Your account also needs permission to use Docker. Include the exact error message.

PowerShell will not run openldr.ps1

Copy the error message and ask your administrator to check how scripts are allowed to run on that computer.

An import cannot find my file

Check the filename, spelling and extension. For a Docker installation, put the file in the installation's data folder and include data/ in the command. For a remote installation, check the server's folder.

I need help with an error

Share the command you ran and its complete error message with your administrator or support contact. For a browser task, include the page and the action you tried.
