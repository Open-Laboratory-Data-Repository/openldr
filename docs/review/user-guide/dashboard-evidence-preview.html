Dashboards

A dashboard brings charts, tables and totals together on one page. Each item is a widget.

Create a dashboard, then choose what each widget should show from your lab's data. You can also configure widgets before records arrive.

Create a dashboard

Create an empty page for the information you want to follow. You can add widgets to it as you need them.

You need permission to create and edit dashboards.

1.Choose New dashboard

Open the dots menu at the top right of Dashboard. Select New dashboard.

Expected result

A blank dashboard opens in edit mode. Its name starts with New dashboard. You can now add widgets.

Add a widget

Add a widget to show a chart, table or total on your dashboard. Choose the lab records it reads, then choose a calculation and chart type.

1.Open the widget editor

A new dashboard is already in edit mode. For an existing dashboard, open its dots menu and select Edit.

Open the dashboard's dots menu and select Add widget.

2.Give the widget a title

Enter a title that describes what the widget will show. For example, use Orders by test for a chart comparing test volumes.

3.Choose the data and calculation

Under Data, choose the records you want to use. Under Summarize, choose the calculation. Count counts records. Other calculations depend on the data you selected.

4.Choose a grouping, if needed

To compare categories, select Group by, then choose a field. For one total, leave the widget without a grouping.

For a date field, use Grain to choose day, week, month, quarter or year.

5.Choose how to display the result

Open the widget editor's dots menu and select Charts.

Choose a type for your result. Number shows one total. Bar compares categories. Line shows changes over time.

6.Save the widget

Open the editor's dots menu and select Save.

7.Check the result on your dashboard

Find the widget by its title. New widgets appear at the bottom. Check that its labels and values describe the data you chose.

8.Finish editing

Open the dashboard's dots menu and select Done.

Expected result

Your widget appears with the title and display you chose. Its values come from your selected data. Repeat the task to add more widgets.

Troubleshooting

The widget shows No data or a zero total

Check whether records have arrived for the data you selected. An empty database can give an empty chart or a zero total. You can save the widget before records arrive.

I cannot find my new widget

New widgets appear at the bottom of the dashboard. Scroll down to find it.

I cannot find the edit action

Ask an administrator to check your dashboard permissions.

Optional: practise with sample data

Use this section to try the controls with fictional records and check known results. It includes the data file and two exercises. You can skip it when building dashboards from your own records.

Load the practice records

The optional exercises below use 60 fictional orders dated September and October 2026. Loading these records lets you check the exact results quoted in those exercises.

Use an empty test installation for this practice. The examples use ~/Downloads/openldr_ce on Linux or macOS and C:\openldr_ce on Windows. Substitute your actual installation folder if it differs.

For opening a terminal, changing folders and running commands, follow the installed CLI walkthrough in Start here. If you run from source, follow the development CLI walkthrough, then use the source-checkout instructions below.

1.Download the sample file

Save the sample in the test installation's data folder. Choose the commands for your operating system.

Linux or macOS
cd ~/Downloads/openldr_ce
curl -fL \
  https://raw.githubusercontent.com/Open-Laboratory-Data-Repository/openldr/main/apps/web/public/docs-samples/openldr-sample-lab-data.json \
  -o data/openldr-sample-lab-data.json

The example saves it at ~/Downloads/openldr_ce/data/openldr-sample-lab-data.json.

Windows PowerShell
cd C:\openldr_ce
Invoke-WebRequest -Uri "https://raw.githubusercontent.com/Open-Laboratory-Data-Repository/openldr/main/apps/web/public/docs-samples/openldr-sample-lab-data.json" -OutFile data/openldr-sample-lab-data.json

The example saves it at C:\openldr_ce\data\openldr-sample-lab-data.json.

2.Import the records

Run the import from the same installation folder. This command writes the practice records into that test installation.

Linux or macOS
cd ~/Downloads/openldr_ce
./openldr ingest data/openldr-sample-lab-data.json
Windows PowerShell
cd C:\openldr_ce
.\openldr.ps1 ingest data/openldr-sample-lab-data.json

Expected result

The command reports 226 resources:

batch <id>: done (226 resources)

Allow a few seconds for the records to appear. The charts you build below will then use the sample's 60 orders.

Running from a source checkout?

The sample file is already included, so you can skip the download above. Use your test checkout at ~/Downloads/openldr_ce or C:\openldr_ce. From that repository root, run:

pnpm openldr ingest apps/web/public/docs-samples/openldr-sample-lab-data.json

The development CLI uses the databases configured in that checkout's .env. See Start here for the development CLI steps.

Try the sample dashboard filters

Use the built-in Lab Overview (Sample) dashboard for this exercise. You will choose a date range, a test and a priority, then read the matching order count.

Your question

How many urgent HIV viral load orders arrived in October?

1.Open Dashboard

Select Dashboard in the main menu on the left.

2.Choose the sample dashboard

In the selector above the charts, choose Lab Overview (Sample). Leave it selected if it is already shown.

3.Set the October date range

Open Period. Go to October 2026, then select 1 followed by 31.

4.Choose the test

Open Test and select HIV viral load.

5.Choose urgent orders

Open Priority and select urgent.

6.Read the answer

Check Total Orders and Distinct Patients below the filters.

Expected result with the practice records

Total Orders and Distinct Patients each read 1. Results Recorded reads 4, because it does not use the Priority filter.

Why did some widgets keep their old values?

Each widget follows its configured filters. Orders by Test compares all tests, so choosing one test does not change it.

My practice totals differ from these numbers

These results assume only the practice records are loaded. Other imported data or extra submitted orders change the totals.
