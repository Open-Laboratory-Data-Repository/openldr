1.Open Dashboard

Select Dashboard near the top of the main menu on the left.

__FOCUS_SHOT:open-dashboard__

2.Open the dashboard menu

Select the dots menu at the right end of the dashboard toolbar, beside Refresh.

__FOCUS_SHOT:open-actions__

3.Choose New dashboard

Select New dashboard at the top of the open menu.

__FOCUS_SHOT:choose-new-dashboard__

Expected result

A blank dashboard opens in edit mode. Its name starts with New dashboard. If that name is already used, OpenLDR adds a number. You can now add widgets.
