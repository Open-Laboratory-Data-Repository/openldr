# Query names

## English

Rename changes only the saved name. Unsaved SQL, connector and parameter changes stay in the tab until Save.

New tabs receive generated names such as Query #1. Choose Save from the query's actions menu. On the first save, a sheet asks for a unique Name. Enter it and choose Save from the sheet's actions menu. The Explorer shows the saved name.

Choose Rename from the query's actions menu to change its name. Its id and report references stay unchanged. If the name exists, the sheet keeps your draft and asks for another name. Cancel closes without saving. Blank names cannot be saved.

Reopen an existing query from Custom Queries to edit it. Saving again updates that same query. Keep saved queries that reports reference. Deleting one is not a naming workaround.

## Français

Renommer modifie uniquement le nom enregistré. Les modifications du SQL, du connecteur et des paramètres restent dans l'onglet jusqu'à Enregistrer.

Les nouveaux onglets reçoivent un nom généré, comme Query #1. Choisissez Enregistrer dans le menu des actions. Au premier enregistrement, un panneau demande un Nom unique. Saisissez-le, puis choisissez Enregistrer dans le menu du panneau. L'explorateur affiche le nom enregistré.

Choisissez Renommer dans le menu des actions. L'identifiant et les références dans les rapports restent inchangés. Si le nom existe déjà, le panneau conserve votre saisie et demande un autre nom. Annuler ferme sans enregistrer. Un nom vide ne peut pas être enregistré.

Rouvrez une requête depuis Custom Queries pour la modifier. Un nouvel enregistrement met à jour cette même requête. Conservez les requêtes utilisées par des rapports. Les supprimer ne constitue pas une solution pour changer leur nom.

## Português

Renomear altera apenas o nome guardado. As alterações de SQL, conector e parâmetros ficam no separador até Guardar.

Os novos separadores recebem nomes gerados, como Query #1. Escolha Guardar no menu de ações. Na primeira gravação, um painel pede um Nome único. Introduza-o e escolha Guardar no menu do painel. O explorador mostra o nome guardado.

Escolha Renomear no menu de ações. O identificador e as referências nos relatórios mantêm-se. Se o nome já existir, o painel mantém o texto introduzido e pede outro nome. Cancelar fecha sem guardar. Não é possível guardar um nome vazio.

Reabra uma consulta em Custom Queries para a editar. Ao guardar novamente, atualiza a mesma consulta. Mantenha as consultas usadas por relatórios. Eliminá-las não é uma solução para mudar o nome.
