# Query groups

## English

A content pack can add many queries at once. Groups keep the Explorer list readable.

- To make a group, open the actions menu on **Custom Queries** and choose **New group**. Enter a name and choose Save from the sheet's actions menu.
- To put a query in a group, drag it onto the group. On a phone, press and hold the query first, or use **Move to group** in the query's actions menu.
- To take a query out of its group, drag it onto **Custom Queries**, or choose **Move to group**, then **No group**.
- Each query row has an actions menu with **Rename**, **Move to group** and **Delete query**. You do not need to open the query in a tab to rename it.
- Each group row has an actions menu with **Rename group** and **Delete group**. Deleting a group keeps its queries. They move out of the group.

Groups only arrange the list. Moving a query does not change its name, SQL or id, so reports that use it keep working.

Groups belong to this install. They are not in export files, and central-to-lab sync does not send or change them.

## Français

Un pack de contenu peut ajouter beaucoup de requêtes d'un coup. Les groupes gardent la liste de l'Explorateur lisible.

- Pour créer un groupe, ouvrez le menu d'actions de **Requêtes personnalisées** et choisissez **Nouveau groupe**. Saisissez un nom, puis choisissez Enregistrer dans le menu du panneau.
- Pour mettre une requête dans un groupe, faites-la glisser sur le groupe. Sur un téléphone, appuyez longuement sur la requête d'abord, ou utilisez **Déplacer vers le groupe** dans le menu d'actions de la requête.
- Pour sortir une requête de son groupe, faites-la glisser sur **Requêtes personnalisées**, ou choisissez **Déplacer vers le groupe**, puis **Aucun groupe**.
- Chaque ligne de requête a un menu d'actions avec **Renommer**, **Déplacer vers le groupe** et **Supprimer la requête**. Il n'est pas nécessaire d'ouvrir la requête dans un onglet pour la renommer.
- Chaque ligne de groupe a un menu d'actions avec **Renommer le groupe** et **Supprimer le groupe**. Supprimer un groupe conserve ses requêtes. Elles sortent du groupe.

Les groupes ne font que ranger la liste. Déplacer une requête ne change ni son nom, ni son SQL, ni son identifiant. Les rapports qui l'utilisent continuent donc de fonctionner.

Les groupes appartiennent à cette installation. Ils ne sont pas dans les fichiers d'export, et la synchronisation du central vers les laboratoires ne les envoie ni ne les modifie.

## Português

Um pacote de conteúdo pode adicionar muitas consultas de uma vez. Os grupos mantêm a lista do Explorador legível.

- Para criar um grupo, abra o menu de ações de **Consultas personalizadas** e escolha **Novo grupo**. Introduza um nome e escolha Guardar no menu do painel.
- Para colocar uma consulta num grupo, arraste-a para o grupo. Num telemóvel, mantenha a consulta premida primeiro, ou use **Mover para o grupo** no menu de ações da consulta.
- Para tirar uma consulta do grupo, arraste-a para **Consultas personalizadas**, ou escolha **Mover para o grupo** e depois **Sem grupo**.
- Cada linha de consulta tem um menu de ações com **Renomear**, **Mover para o grupo** e **Eliminar consulta**. Não precisa de abrir a consulta num separador para a renomear.
- Cada linha de grupo tem um menu de ações com **Renomear grupo** e **Eliminar grupo**. Eliminar um grupo mantém as consultas. Elas saem do grupo.

Os grupos apenas organizam a lista. Mover uma consulta não altera o nome, o SQL nem o identificador, por isso os relatórios que a usam continuam a funcionar.

Os grupos pertencem a esta instalação. Não estão nos ficheiros de exportação, e a sincronização do central para os laboratórios não os envia nem altera.
