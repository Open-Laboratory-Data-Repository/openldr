# Utiliser Studio

Studio est l'interface OpenLDR pour le travail quotidien. Ses pages permettent d'utiliser les tableaux de bord, rapports, workflows, formulaires et terminologies. Les guides détaillés sont dans Studio.

## Ouvrir Studio

Si vous avez installé l'[application de bureau](/docs/desktop-app), ouvrez OpenLDR depuis le menu des applications de votre ordinateur. Studio apparaît dans sa fenêtre.

Si votre laboratoire utilise un serveur partagé, ouvrez l'adresse de Studio fournie par votre administrateur. Utilisez cette adresse sur votre ordinateur ou votre téléphone. Connectez-vous avec votre propre compte.

La personne qui prépare une installation neuve crée le premier administrateur. Pour rejoindre une installation existante, demandez un compte à son administrateur.

## Trouver les guides

1. Ouvrez **Documentation** dans le menu principal de Studio. Sur un téléphone, ouvrez d'abord le menu principal.
2. Choisissez le guide de votre tâche, par exemple Tableau de bord, Rapports, Workflows, Formulaires ou Terminologie.
3. Suivez ses instructions avec les commandes de l'interface Studio.

![Ouvrez Documentation dans le menu principal de Studio pour trouver les guides.](/docs-images/operator/local-open-docs.png)

Vous pouvez utiliser vos propres données. Les données d'exemple sont facultatives.

## Terminer la première configuration

Sur une nouvelle installation, suivez les étapes du premier démarrage de Studio. Elles couvrent le nom du laboratoire, le fuseau horaire, les données d'exemple facultatives et les vérifications d'installation.

Un administrateur peut ensuite revoir les vérifications dans **Paramètres**, puis **Vérifications d'installation**. Le personnel d'une installation existante peut suivre les consignes de configuration de son laboratoire.

## Si vous ne pouvez pas accéder à Studio

Si l'application de bureau ne démarre pas, consultez le dépannage dans [Application de bureau](/docs/desktop-app). Si l'adresse d'un Studio partagé ne s'ouvre pas, contactez la personne qui gère ce serveur.

Pour un problème de compte ou de connexion, contactez votre administrateur. Les administrateurs de serveur trouveront les instructions de configuration et de récupération dans [Fournisseurs d'authentification](/docs/auth-providers).
