# Laboratory setup

## English

In Studio, open Settings → Laboratory. Enter the name, address, contact, and uploaded logo used by report letterheads. Save from the page's ⋯ menu, check the notification, and reopen to verify. Preview a report using the shared letterhead to check its appearance.

Facility register selects an active source registered in Facilities. It supplies the default System for a new facility; it does not import data or change existing identifiers. If the source is missing, register it through Facilities → Import facilities, then reload Laboratory. A failed source request can also leave the selector empty.

Time zone accepts named IANA zones such as `Africa/Dar_es_Salaam`. For SQL Server warehouses, leave it empty and enter the Windows zone in the report's Time zone filter. This setting can supply report filter defaults; it does not control every schedule. The Studio Laboratory guide explains the full procedure.

## Français

Dans Studio, ouvrez Paramètres → Laboratoire. Renseignez le nom, l'adresse, le contact et le fichier du logo utilisés par les en-têtes des rapports. Enregistrez dans le menu ⋯, vérifiez la notification et rouvrez la page. Prévisualisez un rapport utilisant l'en-tête partagé.

Le registre des établissements sélectionne une source active enregistrée dans Établissements. Il fournit le système initial d'un nouvel établissement, sans importer de données ni modifier les identifiants existants. Enregistrez une source manquante depuis l'importation des établissements, puis rechargez Laboratoire. Un échec de chargement peut aussi vider la liste.

Le fuseau horaire accepte les noms IANA, par exemple `Africa/Dar_es_Salaam`. Avec SQL Server, laissez-le vide et saisissez le nom Windows dans le filtre du rapport. Ce réglage peut préremplir des filtres ; il ne règle pas toutes les planifications. Le guide Laboratoire de Studio détaille la procédure.

## Português

No Studio, abra Definições → Laboratório. Preencha o nome, a morada, o contacto e o ficheiro do logótipo usados nos cabeçalhos dos relatórios. Guarde no menu ⋯, confirme a notificação e volte a abrir a página. Pré-visualize um relatório que use o cabeçalho partilhado.

O registo de instalações seleciona uma fonte ativa registada em Instalações. Fornece o sistema inicial de uma nova instalação, sem importar dados nem alterar identificadores existentes. Registe uma fonte em falta através da importação de instalações e recarregue Laboratório. Uma falha de carregamento também pode deixar a lista vazia.

O fuso horário aceita nomes IANA, como `Africa/Dar_es_Salaam`. Com SQL Server, deixe-o vazio e introduza o nome Windows no filtro do relatório. Este valor pode preencher filtros inicialmente; não controla todos os agendamentos. O guia Laboratório do Studio apresenta o procedimento completo.
