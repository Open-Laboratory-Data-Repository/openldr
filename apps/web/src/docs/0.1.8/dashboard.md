# Create a dashboard

## English

In Studio, open Dashboard. Open the dots menu beside the selector and choose **New dashboard**.
The action is available in view and edit modes. Wait for unsaved edits to finish saving first.
Creation stays disabled while a request is pending. The new blank dashboard opens in edit mode.
A confirmation names the dashboard. Choose **Add widget** from the dots menu to add content.
If creation fails, the current dashboard stays selected. Read the error and retry from the menu.

If you edit while creation is pending, save those edits, then select the new dashboard.

Widget and filter editing is unavailable while creation is pending.

## Français

Dans Studio, ouvrez Dashboard. Ouvrez le menu à trois points à côté du sélecteur, puis choisissez **Nouveau tableau de bord**.
L'action est disponible en consultation et en modification. Attendez la fin de l'enregistrement des modifications.
Elle reste désactivée pendant la création. Le tableau de bord vide s'ouvre en mode modification.
Une confirmation indique son nom. Choisissez **Add widget** dans le menu pour ajouter du contenu.
Si la création échoue, le tableau de bord actuel reste sélectionné. Lisez l'erreur, puis réessayez dans le menu.

Si vous modifiez pendant la création, enregistrez ces modifications, puis sélectionnez le nouveau tableau de bord.

La modification des widgets et des filtres est désactivée pendant la création.

## Português

No Studio, abra Dashboard. Abra o menu de três pontos junto ao seletor e escolha **Novo painel**.
A ação está disponível nos modos de visualização e edição. Aguarde até guardar as alterações pendentes.
A ação fica desativada durante a criação. O novo painel vazio abre no modo de edição.
Uma confirmação indica o seu nome. Escolha **Add widget** no menu para adicionar conteúdo.
Se a criação falhar, o painel atual continua selecionado. Leia o erro e tente novamente pelo menu.

Se editar durante a criação, guarde as alterações e selecione o novo painel.

A edição de widgets e filtros fica desativada durante a criação.
