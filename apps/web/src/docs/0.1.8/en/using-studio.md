# Using Studio

Studio is the OpenLDR interface for daily work. Use its pages to work with dashboards, reports, workflows, forms and terminology. The detailed user guides are inside Studio.

## Open Studio

If you installed the [desktop app](/docs/desktop-app), open OpenLDR from your computer's applications menu. Studio appears in its window.

If your laboratory runs a shared server, open the Studio address your administrator gave you. Use that address on your computer or phone. Sign in with your own account.

The person setting up a fresh installation creates the first administrator. If you are joining an existing installation, ask its administrator for an account.

## Find the user guides

1. Open **Docs** in Studio's main menu. On a phone, open the main menu first.
2. Choose the guide for your task, such as Dashboard, Reports, Workflows, Forms or Terminology.
3. Follow its instructions using the controls in Studio.

![Open Docs in Studio's main menu to find the user guides.](/docs-images/operator/local-open-docs.png)

You can use your own data throughout. Sample data is optional.

The guide list shows only the guides for pages you can use. If a guide you expect is missing, ask your administrator for the permission. A link to any guide still opens it.

## Finish the first setup

On a new installation, follow Studio's first-run steps. They cover the laboratory name, time zone, optional sample data and setup checks.

Later, an administrator can review the checks under **Settings**, then **Setup checks**. Staff using an existing installation can follow their laboratory's setup instructions.

## If you cannot get in

If the desktop app will not start, use the troubleshooting section in [Desktop app](/docs/desktop-app). If a shared Studio address will not open, contact the person who runs that server.

For an account or sign-in problem, contact your administrator. Server administrators can use [Authentication providers](/docs/auth-providers) for setup and recovery instructions.
