# Usar o Studio

O Studio é a interface do OpenLDR para o trabalho diário. As suas páginas permitem usar painéis, relatórios, workflows, formulários e terminologias. Os guias detalhados estão dentro do Studio.

## Abrir o Studio

Se instalou a [aplicação de ambiente de trabalho](/docs/desktop-app), abra o OpenLDR no menu de aplicações do computador. O Studio aparece na sua janela.

Se o seu laboratório usa um servidor partilhado, abra o endereço do Studio fornecido pelo administrador. Use esse endereço no computador ou no telemóvel. Inicie sessão com a sua própria conta.

A pessoa que prepara uma instalação nova cria o primeiro administrador. Para entrar numa instalação existente, peça uma conta ao administrador.

## Encontrar os guias

1. Abra **Documentação** no menu principal do Studio. Num telemóvel, abra primeiro o menu principal.
2. Escolha o guia da sua tarefa, como Painel, Relatórios, Workflows, Formulários ou Terminologia.
3. Siga as instruções usando os controlos do Studio.

![Abra Documentação no menu principal do Studio para encontrar os guias.](/docs-images/operator/local-open-docs.png)

Pode usar os seus próprios dados. Os dados de exemplo são opcionais.

## Terminar a primeira configuração

Numa instalação nova, siga os passos do primeiro arranque do Studio. Incluem o nome do laboratório, fuso horário, dados de exemplo opcionais e verificações de configuração.

Mais tarde, um administrador pode rever as verificações em **Definições**, depois **Verificações de instalação**. O pessoal de uma instalação existente pode seguir as instruções de configuração do laboratório.

## Se não conseguir entrar

Se a aplicação de ambiente de trabalho não iniciar, consulte a resolução de problemas em [Aplicação de ambiente de trabalho](/docs/desktop-app). Se o endereço de um Studio partilhado não abrir, contacte a pessoa que mantém esse servidor.

Para um problema de conta ou de início de sessão, contacte o administrador. Os administradores de servidor podem consultar as instruções de configuração e recuperação em [Fornecedores de autenticação](/docs/auth-providers).
