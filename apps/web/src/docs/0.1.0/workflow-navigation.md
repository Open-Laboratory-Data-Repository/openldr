# Workflow canvas navigation

## English

Open a workflow in Studio to use its canvas controls.

- At the bottom left, **+** zooms in and **−** zooms out.
- Select **Fit View**, below the zoom buttons, to bring all nodes into view.
- Select the hand icon at the top left for **Pan** mode.
  Drag an empty canvas area to move the view.
- In **Select** mode, the pointer icon, left-drag selects nodes in a box.
  Drag with the middle or right mouse button to move the view.

The bottom-right minimap also supports panning and zooming.
If nodes leave the visible area, use **Fit View** before moving any nodes.
Navigation changes the view, not the saved node positions.

## Français

Ouvrez un flux de travail dans Studio pour accéder aux commandes du canevas.

- En bas à gauche, **+** agrandit la vue et **−** la réduit.
- **Fit View**, sous les boutons de zoom, affiche tous les nœuds.
- Choisissez la main en haut à gauche pour le mode **Pan**.
  Faites glisser une zone vide du canevas pour déplacer la vue.
- En mode **Select**, l'icône de pointeur, un glissement avec le bouton gauche
  sélectionne les nœuds dans un rectangle. Utilisez le bouton central ou droit pour déplacer la vue.

La minicarte en bas à droite permet aussi de déplacer et de zoomer la vue.
Si les nœuds sortent du cadre, utilisez **Fit View** avant de déplacer un nœud.
Ces commandes ne changent pas les positions enregistrées des nœuds.

## Português

Abra um fluxo de trabalho no Studio para aceder aos controlos da área de trabalho.

- No canto inferior esquerdo, **+** aproxima a vista e **−** afasta a vista.
- **Fit View**, abaixo dos botões de zoom, mostra todos os nós.
- Escolha a mão no canto superior esquerdo para o modo **Pan**.
  Arraste uma zona vazia da área de trabalho para deslocar a vista.
- No modo **Select**, o ícone de ponteiro, arrastar com o botão esquerdo
  seleciona os nós num retângulo. Use o botão central ou direito para deslocar a vista.

O minimapa no canto inferior direito também permite deslocar a vista e alterar o zoom.
Se perder os nós de vista, use **Fit View** antes de mover um nó.
Estes controlos não alteram as posições guardadas dos nós.
