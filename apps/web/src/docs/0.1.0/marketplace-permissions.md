# Marketplace permission checks

## English

In Studio, open Settings, Marketplace, then a package's details.

- **Loading permissions** means package details are still loading. Install remains disabled.
- **Permissions unavailable** means the permission list could not be established. It does not mean no permissions are requested.
- **No special permissions requested** means the loaded details confirm an empty list. Installed packages without a registry reference use their stored local permissions.

Selecting another version repeats the check. Review that version's permissions in the installation approval before confirming. If details fail to load, check registry availability and reopen the package.

## Français

Dans Studio, ouvrez Paramètres, Marketplace, puis les détails d'un paquet.

- **Chargement des permissions** indique que les détails sont en cours de récupération. L'installation reste désactivée.
- **Permissions indisponibles** indique que les permissions n'ont pas pu être établies. Cela ne signifie pas que le paquet ne demande aucune permission.
- **Aucune permission particulière demandée** indique que les détails chargés confirment une liste vide. Les paquets installés sans référence au registre utilisent leurs permissions locales enregistrées.

Un changement de version relance cette vérification. Vérifiez les permissions de cette version dans la demande d'approbation avant de confirmer. En cas d'échec du chargement, vérifiez la disponibilité du registre et rouvrez le paquet.

## Português

No Studio, abra Definições, Marketplace e os detalhes de um pacote.

- **A carregar permissões** indica que os detalhes estão a ser obtidos. A instalação permanece desativada.
- **Permissões indisponíveis** indica que não foi possível determinar as permissões. Não significa que o pacote não solicita permissões.
- **Nenhuma permissão especial solicitada** indica que os detalhes carregados confirmam uma lista vazia. Os pacotes instalados sem referência ao registo usam as permissões locais guardadas.

Escolher outra versão repete a verificação. Confira as permissões dessa versão no pedido de aprovação antes de confirmar. Se os detalhes não carregarem, verifique a disponibilidade do registo e volte a abrir o pacote.
