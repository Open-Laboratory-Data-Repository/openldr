# Dashboard refresh

## English

Each dashboard widget loads immediately. With automatic refresh enabled, its interval starts after the request finishes. A slow request delays the next refresh instead of starting overlapping requests for that widget. An interval of zero disables automatic refresh.

Changing the query or filters cancels the obsolete browser request. Leaving the dashboard cancels pending widget requests. Late responses cannot replace newer results. A successful refresh clears the previous error.

Cancelling a browser request does not guarantee that the database query stops.

## Français

Chaque widget du tableau de bord se charge immédiatement. Si l'actualisation automatique est activée, son délai commence après la fin de la requête. Une requête lente retarde la prochaine actualisation. Le widget ne lance pas de requêtes simultanées. Un délai de zéro désactive l'actualisation automatique.

Modifier la requête ou les filtres annule la requête obsolète dans le navigateur. Quitter le tableau de bord annule les requêtes en attente. Les réponses tardives ne remplacent pas les résultats récents. Une actualisation réussie efface l'erreur précédente.

Annuler une requête dans le navigateur ne garantit pas son arrêt dans la base de données.

## Português

Cada widget do painel carrega imediatamente. Com a atualização automática ativa, o intervalo começa após o pedido terminar. Um pedido lento adia a próxima atualização. O widget não inicia pedidos simultâneos. Um intervalo de zero desativa a atualização automática.

Alterar a consulta ou os filtros cancela o pedido obsoleto no navegador. Sair do painel cancela os pedidos pendentes. As respostas tardias não substituem os resultados recentes. Uma atualização bem-sucedida remove o erro anterior.

Cancelar um pedido no navegador não garante que a consulta pare na base de dados.
