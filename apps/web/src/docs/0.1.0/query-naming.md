# Query names

## English

New tabs in Studio's Query workbench receive generated names such as `Query #1`. Save uses the tab title as the Custom Query name. It does not ask for a name.

The workbench has no name field, rename action, or duplicate action. Creating another query does not let you choose its name.

Reopen an existing query from Custom Queries to edit it. Saving again updates that same query. Keep saved queries that reports reference. Deleting one is not a naming workaround.

## Français

Les nouveaux onglets de l'espace Query de Studio reçoivent un nom généré, comme `Query #1`. Save utilise le titre de l'onglet comme nom de la requête personnalisée. Aucun champ ne demande un nom.

Cet espace ne propose ni champ de nom, ni action pour renommer ou dupliquer une requête. Créer une autre requête ne permet pas de choisir son nom.

Rouvrez une requête depuis Custom Queries pour la modifier. Un nouvel enregistrement met à jour cette même requête. Conservez les requêtes utilisées par des rapports. Les supprimer ne constitue pas une solution pour changer leur nom.

## Português

Os novos separadores do espaço Query do Studio recebem nomes gerados, como `Query #1`. Save usa o título do separador como nome da consulta personalizada. Não existe um campo para indicar o nome.

Este espaço não tem um campo de nome nem ações para renomear ou duplicar consultas. Criar outra consulta não permite escolher o nome.

Reabra uma consulta em Custom Queries para a editar. Ao guardar novamente, atualiza a mesma consulta. Mantenha as consultas usadas por relatórios. Eliminá-las não é uma solução para mudar o nome.
