# As suas preferências

Escolha o idioma, a aparência e a página inicial do Studio. Estas preferências pertencem à sua conta. Pode alterá-las quando precisar.

As alterações ficam guardadas automaticamente. Não precisa de dados de exemplo para seguir este guia.

## Mudar de idioma

Use o Studio em inglês, francês ou português. Este exemplo muda para francês para mostrar a alteração.

### 1. Abrir o menu do utilizador

Selecione o seu nome no canto inferior esquerdo do menu principal. Se a barra lateral mostrar apenas ícones, selecione a sua inicial.

![O seu nome ou inicial abre o menu do utilizador.](preferences-guide-user-menu-button.png)

### 2. Abrir Idioma

Selecione **Idioma** no menu do utilizador.

![Idioma encontra-se no menu do utilizador.](preferences-guide-language-menu.png)

### 3. Escolher Français

Selecione **Français**. O idioma atual aparece a cinzento.

![Escolha Français no submenu Idioma.](preferences-guide-language-french.png)

**Resultado esperado:** o menu principal e este guia passam para francês. Dashboard passa a **Tableau de bord** e Reports passa a **Rapports**.

![Os nomes no menu passam para francês.](preferences-guide-language-result.png)

Para voltar ao inglês, abra o menu do utilizador, selecione **Langue** e depois **English**. Algumas páginas ainda contêm texto em inglês.

## Alternar entre o tema claro e o escuro

Escolha a aparência mais fácil de ler no seu ecrã. Este exemplo começa no modo escuro.

### 1. Selecionar o botão do tema

Selecione o sol no canto superior direito. No modo claro, a mesma posição tem uma lua.

![O botão do tema encontra-se no canto superior direito.](preferences-guide-theme-button.png)

**Resultado esperado:** o Studio passa para o modo claro. Selecione a lua para voltar ao modo escuro.

![A página passa para o modo claro.](preferences-guide-theme-result.png)

Também pode carregar em `d` quando não estiver a escrever num campo.

## Escolher a página que abre primeiro

Se costuma começar por ler relatórios, escolha Relatórios como página inicial. Pode escolher qualquer página apresentada na sua lista.

### 1. Abrir o menu do utilizador

Selecione o seu nome ou inicial no canto inferior esquerdo do menu principal.

![O seu nome ou inicial abre o menu do utilizador.](preferences-guide-user-menu-button.png)

### 2. Abrir Página inicial

Selecione **Página inicial**. A lista segue as páginas disponíveis na sua barra lateral.

![Página inicial encontra-se no menu do utilizador.](preferences-guide-start-page-menu.png)

### 3. Escolher Relatórios

Selecione **Relatórios**, ou a página que preferir.

![Escolha Relatórios entre as páginas disponíveis.](preferences-guide-start-page-reports.png)

**Guardado:** uma mensagem indica que **Relatórios abre primeiro depois de iniciar sessão.** A escolha não muda de página imediatamente.

### 4. Reabrir o Studio no endereço principal

Abra o endereço que costuma usar para entrar no Studio, sem uma ligação para uma página específica.

![Reabrir o Studio no endereço principal abre Relatórios.](preferences-guide-start-page-result.png)

**Resultado esperado:** Relatórios abre primeiro. Um favorito para uma página específica continua a abrir essa página.

Para voltar a abrir o painel primeiro, escolha **Painel** em **Página inicial**.

## Dar mais espaço à página

Num computador, recolha a barra lateral principal para ganhar espaço de trabalho. Os ícones continuam disponíveis.

### 1. Recolher a barra lateral

Selecione **Recolher barra lateral**, o botão junto ao OpenLDR no canto superior esquerdo.

![O botão de recolher encontra-se junto ao OpenLDR no canto superior esquerdo.](preferences-guide-sidebar-collapse.png)

### 2. Expandir para ver os nomes

Selecione **Expandir barra lateral** no topo da barra estreita.

![A mesma posição permite agora expandir a barra lateral.](preferences-guide-sidebar-expand.png)

**Resultado esperado:** os nomes das páginas voltam a aparecer. O Studio memoriza se deixa a barra lateral expandida ou recolhida.

Quando a janela é demasiado baixa para todas as páginas, a barra lateral não desliza nem encolhe os ícones. Mantém cada página do mesmo tamanho e põe as que não cabem em **Mais** (**⋯**), em baixo. Funciona da mesma forma num telemóvel e num computador, com a barra aberta ou recolhida.

## Encontrar as preferências num telemóvel

O menu principal fica recolhido num telemóvel. Abra-o para escolher o idioma e a página inicial.

### 1. Abrir o menu principal

Selecione o botão do menu no canto superior esquerdo.

![Num telemóvel, abra o menu principal no canto superior esquerdo.](preferences-guide-phone-open-menu.png)

### 2. Abrir o menu do utilizador

Selecione o seu nome no fundo do menu principal aberto.

![O seu nome encontra-se no fundo do menu principal aberto.](preferences-guide-phone-user-menu.png)

**Resultado esperado:** aparecem **Idioma** e **Página inicial**. Continue com os passos anteriores. O botão do tema permanece no cabeçalho.

![Idioma e Página inicial estão disponíveis no menu do telemóvel.](preferences-guide-phone-menu-result.png)

## O que o Studio memoriza

O idioma, o tema, o estado da barra lateral e a página inicial ficam guardados na sua conta. São carregados quando inicia sessão noutro navegador ou dispositivo.

O laboratório também pode disponibilizar disposições com nome para a barra lateral. Se **Disposição** aparecer no menu do utilizador, o [guia Disposições](/docs/layouts) explica essas escolhas.

Sem uma escolha pessoal, o Studio usa a página inicial da sua disposição quando está disponível. Caso contrário, abre o painel. Escolher **Painel** explicitamente faz com que abra primeiro.

## Resolução de problemas

**A página escolhida não abre primeiro**

Reabra o Studio no endereço principal. Um favorito para outra página continua a abrir essa página. A página inicial escolhida tem de continuar disponível na barra lateral.

**Uma escolha aparece a cinzento**

Esse idioma ou página inicial já está selecionado. Escolha outro elemento para o alterar.

**Não vejo Disposição**

O submenu Disposição só aparece quando existe uma disposição com nome. Idioma, tema e Página inicial funcionam sem uma disposição.

**Uma mensagem indica que não foi possível guardar a página inicial**

Verifique a ligação ao Studio e escolha novamente a página. Confirme que aparece a mensagem de sucesso.
