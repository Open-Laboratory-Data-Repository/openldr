# Disposições

Uma disposição é uma barra lateral com nome. Os administradores escolhem as páginas e a página inicial opcional e definem-na como predefinição para funções escolhidas. Cada pessoa pode escolher outra disposição no menu de utilizador.

Uma disposição apenas oculta páginas. Nunca concede permissão para as abrir. Docs continua disponível. A sua função continua a controlar o acesso.

Escolha páginas adequadas ao pessoal. As imagens usam uma disposição temporária Documentation review numa instalação de teste. Não precisa de dados de exemplo.

Edit general settings permite criar, editar e eliminar disposições. View roles permite consultar as funções disponíveis para predefinições. Qualquer pessoa autenticada pode escolher uma disposição disponível.

## Criar uma barra lateral para uma equipa

Use esta tarefa quando uma equipa precisar de uma barra lateral mais curta e de uma primeira página adequada. Escolha as páginas segundo o trabalho da equipa.

### 1. Abrir Settings e Layouts

Abra o menu de utilizador no canto inferior esquerdo, escolha **Settings** e selecione **Layouts**.

![Abra o menu de utilizador no canto inferior esquerdo.](layouts-guide-user-menu.png)

![Escolha Settings.](layouts-guide-settings-menu.png)

![Selecione Layouts em Settings.](layouts-guide-layouts-page.png)

### 2. Escolher New layout

Abra os pontos da página no canto superior direito e selecione **New layout**.

![Abra o menu de pontos de Layouts.](layouts-guide-page-actions.png)

![Escolha New layout.](layouts-guide-new-layout.png)

### 3. Dar um nome à disposição

Introduza um **Name** claro. O exemplo usa `Documentation review`.

![Dê um nome à disposição segundo o uso previsto.](layouts-guide-name.png)

### 4. Escolher as páginas

Selecione as páginas a mostrar nesta barra lateral. Escolha pelo menos uma. Docs continua sempre disponível e não tem caixa de seleção.

![Selecione as páginas a mostrar. Docs continua sempre disponível.](layouts-guide-pages.png)

### 5. Escolher a página inicial

Abra **Start page** e escolha uma página selecionada. O exemplo escolhe Reports. A opção predefinida é Dashboard.

![Escolha a página a abrir primeiro. Só são propostas páginas selecionadas.](layouts-guide-start-page.png)

### 6. Escolher as predefinições de funções

Em **Default for roles**, selecione as funções que devem usar esta disposição por predefinição. Deixe vazio se as pessoas a escolherem individualmente.

![Pode definir esta disposição como predefinição para funções escolhidas.](layouts-guide-role-default.png)

### 7. Guardar a disposição

Abra os pontos do editor no canto superior direito e selecione **Save**.

![Abra os pontos do editor da disposição.](layouts-guide-sheet-actions.png)

![Escolha Save.](layouts-guide-save-layout.png)

**Resultado esperado:** a tabela mostra a disposição guardada, o número de páginas, a página inicial e as predefinições de funções.

![A tabela mostra o número de páginas, a página inicial e a predefinição de função guardados.](layouts-guide-created-result.png)

## Alterar uma disposição existente

Use esta tarefa quando uma equipa precisar de outras páginas. Os utilizadores que escolheram a disposição recebem as alterações guardadas.

### 1. Abrir as ações da linha

Encontre a disposição e selecione os pontos da linha.

![Abra os pontos da disposição correta.](layouts-guide-row-actions.png)

### 2. Escolher Edit

Selecione **Edit**.

![Escolha Edit.](layouts-guide-edit-layout.png)

### 3. Alterar as páginas

Selecione ou desmarque páginas. O exemplo acrescenta **Activity**. Remover a página inicial selecionada limpa essa escolha.

![Altere as páginas selecionadas. O exemplo acrescenta Activity.](layouts-guide-edit-page.png)

### 4. Guardar as alterações

Abra os pontos do editor e selecione **Save**.

![Escolha Save no menu de pontos do editor.](layouts-guide-edit-save.png)

**Resultado esperado:** a tabela reflete a seleção de páginas guardada.

![O número de páginas reflete a seleção alterada.](layouts-guide-edited-result.png)

## Escolher uma disposição pessoal

Use esta tarefa quando preferir outra barra lateral disponível. A escolha pessoal sobrepõe-se à predefinição da função.

### 1. Abrir o menu de utilizador

Selecione o menu de utilizador no canto inferior esquerdo.

![Abra o menu de utilizador para escolher uma barra lateral.](layouts-guide-pick-user-menu.png)

### 2. Abrir Layout

Abra **Layout**. Este menu aparece quando existe pelo menos uma disposição com nome.

![Abra Layout.](layouts-guide-pick-layout-menu.png)

### 3. Escolher a disposição com nome

Selecione a disposição pretendida. O exemplo escolhe **Documentation review**.

![Escolha a disposição com nome.](layouts-guide-pick-layout.png)

**Resultado esperado:** a barra lateral mostra as páginas da disposição permitidas pela função. Docs continua visível. Uma escolha pessoal de Start page pode substituir a página inicial da disposição.

![A barra lateral mostra as páginas selecionadas e Docs.](layouts-guide-picked-result.png)

## Regressar à predefinição da função ou à barra completa

Use esta tarefa para regressar à predefinição da função ou a todas as páginas permitidas pela função.

### 1. Escolher Role default

Abra o menu de utilizador e Layout. Selecione **Role default** para limpar a escolha pessoal. O menu indica a predefinição atual entre parênteses retos.

![Role default segue a predefinição definida pelos administradores.](layouts-guide-role-default-option.png)

### 2. Escolher Full sidebar quando necessário

Para mostrar todas as páginas permitidas, abra o mesmo menu Layout e selecione **Full sidebar**.

![Escolha Full sidebar para mostrar todas as páginas permitidas.](layouts-guide-full-sidebar.png)

**Resultado esperado:** a barra lateral completa regressa. As permissões continuam a decidir as páginas visíveis.

![A barra lateral completa regressa segundo as permissões da função.](layouts-guide-full-result.png)

## Remover uma disposição sem uso

Use esta tarefa quando uma barra com nome deixar de ser necessária. Confira as predefinições de funções afetadas antes de eliminar.

### 1. Escolher Delete

Abra os pontos da linha correta e selecione **Delete**.

![Escolha Delete para a disposição correta.](layouts-guide-delete-layout.png)

### 2. Confirmar a alternativa

Confira o nome. As pessoas que a escolheram regressam à predefinição da função. As funções que a usam perdem essa predefinição. Selecione **Delete layout** para confirmar.

![Confira o nome e o comportamento de substituição antes de confirmar.](layouts-guide-delete-confirm.png)

**Resultado esperado:** a disposição desaparece da lista.

![A disposição é removida da lista.](layouts-guide-deleted-result.png)

## Editar disposições num telemóvel

Use a mesma página Layouts no telemóvel. A lista de secções de Settings desloca-se horizontalmente.

### 1. Abrir Layouts

Selecione **Layouts** na lista de secções de Settings.

![Use Layouts na lista horizontal de secções de Settings no telemóvel.](layouts-guide-phone-layouts.png)

### 2. Abrir o editor

Abra os pontos da linha e escolha Edit. Desloque o painel para chegar às páginas e funções.

![O editor usa a largura do telemóvel. Desloque-o para chegar às páginas e predefinições de funções.](layouts-guide-phone-editor.png)

## Prática opcional

Numa instalação de teste, crie `Documentation review` com Dashboard, Reports e Forms. Escolha Reports como página inicial. Experimente-a no menu de utilizador, reponha Full sidebar e elimine a disposição de teste.

## Limites

As disposições não concedem permissões nem alteram dados. As páginas mantêm a ordem habitual. As escolhas pessoais de disposição e página inicial podem substituir a predefinição da função.

## Resolução de problemas

**Uma página selecionada não aparece.** Confira se a função permite abri-la. Acrescentar uma página não concede acesso.

**A primeira página esperada não abre.** Confira a escolha pessoal de Start page no menu de utilizador.

**Não é possível ler as predefinições de funções.** O editor mantém as existentes. Peça a um administrador com View roles para as rever.
