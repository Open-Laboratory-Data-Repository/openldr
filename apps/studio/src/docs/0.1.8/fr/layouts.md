# Présentations

Une présentation est une barre latérale nommée. Les administrateurs choisissent ses pages et sa page d'accueil facultative, puis l'affectent par défaut à certains rôles. Chacun peut choisir une autre présentation dans son menu utilisateur.

Une présentation masque seulement des pages. Elle n'accorde jamais le droit de les ouvrir. Docs reste disponible. Votre rôle contrôle toujours les accès.

Choisissez les pages adaptées au personnel. Les images montrent une présentation temporaire Documentation review dans une installation de test. Aucun exemple de données n'est requis.

Edit general settings permet de créer, modifier et supprimer des présentations. View roles permet de consulter les rôles proposés pour les valeurs par défaut. Toute personne connectée peut choisir une présentation disponible.

## Créer une barre latérale pour une équipe

Utilisez cette tâche lorsqu'une équipe a besoin d'une barre latérale plus courte et d'une première page adaptée. Choisissez les pages selon son travail.

### 1. Ouvrir Settings et Layouts

Ouvrez votre menu utilisateur en bas à gauche, choisissez **Settings**, puis **Layouts**.

![Ouvrez votre menu utilisateur en bas à gauche.](layouts-guide-user-menu.png)

![Choisissez Settings.](layouts-guide-settings-menu.png)

![Sélectionnez Layouts dans Settings.](layouts-guide-layouts-page.png)

### 2. Choisir New layout

Ouvrez les points de la page en haut à droite et sélectionnez **New layout**.

![Ouvrez le menu de points de Layouts.](layouts-guide-page-actions.png)

![Choisissez New layout.](layouts-guide-new-layout.png)

### 3. Nommer la présentation

Saisissez un **Name** clair. L'exemple utilise `Documentation review`.

![Nommez la présentation selon son usage prévu.](layouts-guide-name.png)

### 4. Choisir les pages

Sélectionnez les pages à afficher dans cette barre latérale. Choisissez-en au moins une. Docs reste toujours disponible et n'a pas de case à cocher.

![Sélectionnez les pages à afficher. Docs reste toujours disponible.](layouts-guide-pages.png)

### 5. Choisir la page d'accueil

Ouvrez **Start page** et choisissez une page sélectionnée. L'exemple choisit Reports. L'option par défaut est Dashboard.

![Choisissez la première page à ouvrir. Seules les pages sélectionnées sont proposées.](layouts-guide-start-page.png)

### 6. Choisir les rôles par défaut

Dans **Default for roles**, sélectionnez les rôles qui doivent utiliser cette présentation par défaut. Ne cochez rien si les personnes la choisiront elles-mêmes.

![Vous pouvez définir cette présentation par défaut pour certains rôles.](layouts-guide-role-default.png)

### 7. Enregistrer la présentation

Ouvrez les points de l'éditeur en haut à droite et sélectionnez **Save**.

![Ouvrez les points de l'éditeur de présentation.](layouts-guide-sheet-actions.png)

![Choisissez Save.](layouts-guide-save-layout.png)

**Résultat attendu :** la table affiche la présentation enregistrée, le nombre de pages, la page d'accueil et les rôles par défaut.

![La table affiche le nombre de pages, la page d'accueil et le rôle par défaut enregistrés.](layouts-guide-created-result.png)

## Modifier une présentation existante

Utilisez cette tâche lorsqu'une équipe a besoin d'autres pages. Les personnes ayant choisi cette présentation reçoivent ses modifications enregistrées.

### 1. Ouvrir les actions de la ligne

Trouvez la présentation et sélectionnez les points de sa ligne.

![Ouvrez les points de la bonne présentation.](layouts-guide-row-actions.png)

### 2. Choisir Edit

Sélectionnez **Edit**.

![Choisissez Edit.](layouts-guide-edit-layout.png)

### 3. Modifier les pages

Cochez ou décochez les pages. L'exemple ajoute **Activity**. Retirer la page d'accueil sélectionnée efface ce choix.

![Modifiez les pages sélectionnées. L'exemple ajoute Activity.](layouts-guide-edit-page.png)

### 4. Enregistrer les modifications

Ouvrez les points de l'éditeur et sélectionnez **Save**.

![Choisissez Save dans le menu de points de l'éditeur.](layouts-guide-edit-save.png)

**Résultat attendu :** la table reflète la sélection de pages enregistrée.

![Le nombre de pages reflète la sélection modifiée.](layouts-guide-edited-result.png)

## Choisir votre présentation personnelle

Utilisez cette tâche pour choisir une autre barre latérale disponible. Votre choix personnel remplace le défaut du rôle.

### 1. Ouvrir votre menu utilisateur

Sélectionnez votre menu utilisateur en bas à gauche.

![Ouvrez votre menu utilisateur pour choisir une barre latérale.](layouts-guide-pick-user-menu.png)

### 2. Ouvrir Layout

Ouvrez **Layout**. Ce menu apparaît lorsqu'au moins une présentation nommée existe.

![Ouvrez Layout.](layouts-guide-pick-layout-menu.png)

### 3. Choisir la présentation nommée

Sélectionnez la présentation voulue. L'exemple choisit **Documentation review**.

![Choisissez la présentation nommée.](layouts-guide-pick-layout.png)

**Résultat attendu :** la barre latérale affiche les pages de la présentation autorisées par votre rôle. Docs reste visible. Un choix personnel Start page peut remplacer la page d'accueil de la présentation.

![La barre latérale affiche les pages sélectionnées et Docs.](layouts-guide-picked-result.png)

## Revenir au défaut du rôle ou à la barre complète

Utilisez cette tâche pour retrouver le défaut défini par l'administrateur ou toutes les pages permises par votre rôle.

### 1. Choisir Role default

Ouvrez votre menu utilisateur, puis Layout. Sélectionnez **Role default** pour effacer votre choix personnel. Le menu indique le défaut actuel entre crochets.

![Role default suit le défaut défini par les administrateurs.](layouts-guide-role-default-option.png)

### 2. Choisir Full sidebar si nécessaire

Pour afficher toutes les pages autorisées, ouvrez le même menu Layout et sélectionnez **Full sidebar**.

![Choisissez Full sidebar pour afficher toutes les pages autorisées.](layouts-guide-full-sidebar.png)

**Résultat attendu :** la barre latérale complète revient. Les permissions déterminent toujours les pages visibles.

![La barre complète revient selon les permissions de votre rôle.](layouts-guide-full-result.png)

## Supprimer une présentation inutilisée

Utilisez cette tâche lorsqu'une barre nommée n'est plus nécessaire. Vérifiez les défauts de rôles concernés avant suppression.

### 1. Choisir Delete

Ouvrez les points de la bonne ligne et sélectionnez **Delete**.

![Choisissez Delete pour la bonne présentation.](layouts-guide-delete-layout.png)

### 2. Confirmer le remplacement

Vérifiez le nom. Les personnes l'ayant choisie reviennent au défaut de leur rôle. Les rôles qui l'utilisent perdent ce défaut. Sélectionnez **Delete layout** pour confirmer.

![Vérifiez le nom et le comportement de remplacement avant confirmation.](layouts-guide-delete-confirm.png)

**Résultat attendu :** la présentation disparaît de la liste.

![La présentation est retirée de la liste.](layouts-guide-deleted-result.png)

## Modifier les présentations sur téléphone

Utilisez la même page Layouts sur téléphone. La liste des sections de Settings défile horizontalement.

### 1. Ouvrir Layouts

Sélectionnez **Layouts** dans la liste des sections de Settings.

![Utilisez Layouts dans la liste horizontale des sections de Settings sur téléphone.](layouts-guide-phone-layouts.png)

### 2. Ouvrir l'éditeur

Ouvrez les points de la ligne et choisissez Edit. Faites défiler le panneau pour atteindre les pages et les rôles.

![L'éditeur utilise la largeur du téléphone. Faites défiler pour accéder aux pages et aux défauts des rôles.](layouts-guide-phone-editor.png)

## Exercice facultatif

Dans une installation de test, créez `Documentation review` avec Dashboard, Reports et Forms. Choisissez Reports comme page d'accueil. Essayez-la dans le menu utilisateur, rétablissez Full sidebar, puis supprimez la présentation de test.

## Limites

Les présentations n'accordent aucune permission et ne modifient pas les données. Les pages gardent leur ordre standard. Les choix personnels de présentation et de page d'accueil peuvent remplacer le défaut du rôle.

## Dépannage

**Une page sélectionnée n'apparaît pas.** Vérifiez si votre rôle permet de l'ouvrir. Ajouter une page ne donne pas accès.

**La première page attendue ne s'ouvre pas.** Vérifiez votre choix personnel Start page dans le menu utilisateur.

**Les défauts des rôles sont illisibles.** L'éditeur conserve les défauts existants. Demandez à un administrateur disposant de View roles de les vérifier.
