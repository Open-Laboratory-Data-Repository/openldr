# Começar aqui

## Objetivo

Encontre Painel, Relatórios e Documentação. Abra os parâmetros de um relatório e encontre Executar.
As imagens numeradas mostram a interface inglesa com exemplos fictícios, sem dados de pacientes.

## Antes de começar

Entre no Studio. As páginas visíveis dependem das permissões da sua conta.
No telefone, abra primeiro o menu de navegação. Selecione uma imagem para a ampliar.

## Passos

![Navegação: 1 Painel, 2 Relatórios, 3 Documentação. Unidades também está visível.](start-here-navigation.png)

1. Abra **Painel** para consultar os painéis partilhados com a sua conta.
2. Abra **Relatórios** para consultar a biblioteca.
3. Abra **Documentação** e procure uma tarefa na pesquisa. Volte aqui depois de consultar um guia.

A navegação também inclui **Unidades** quando a sua conta pode consultá-las.
Peça ao administrador as permissões necessárias para uma página ausente.

![Menu do relatório: 4 Parameters, os parâmetros](start-here-report-menu.png)

4. Volte a **Relatórios**, selecione um relatório e abra o menu **⋯**. Escolha **Parâmetros**.

![Parâmetros: 5 campo de exemplo, 6 Run, executar](start-here-parameters.png)

5. Preencha os parâmetros obrigatórios. Cada relatório define os seus campos. Este exemplo usa um campo de texto.
6. Selecione **Executar** quando os valores obrigatórios estiverem preenchidos. O relatório usa esses valores.

A captura termina antes da execução. O resultado depende do relatório e dos dados disponíveis.
Encontre o [guia Relatórios](/docs/reports) na documentação.
Use os guias relacionados e as ligações anterior e seguinte para continuar a leitura.

## Resultado esperado

Consegue encontrar estas páginas, pesquisar no manual e abrir os parâmetros de um relatório.

## Resolução de problemas

- Falta uma página. Peça ao administrador para verificar as permissões.
- Executar está desativado. Preencha todos os parâmetros obrigatórios.
- A imagem é pequena. Selecione-a para a ampliar. O texto numerado também explica cada ação.
- A pesquisa tem demasiados resultados. Procure a tarefa ou a mensagem de erro exata.

## Filtrar tabelas

Conforme a página, a barra permite pesquisar, filtrar, ordenar e escolher colunas.
A pesquisa acompanha a escrita. Adicione um filtro com coluna, operador e valor, e aplique-o.
Remova uma regra pela sua etiqueta ou limpe todos os filtros.
