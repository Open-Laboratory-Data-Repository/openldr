# Funções

Uma função reúne permissões, como consultar relatórios ou editar workflows. Em **Definições → Funções**, pode consultar as permissões e o número de membros de cada função.

## Atribuir uma função a um utilizador

A atribuição é feita na conta, em **Utilizadores**.

1. Abra o menu **⋯** da conta e escolha **Editar**.
2. Aguarde o carregamento de **Função** e selecione uma única função.
3. Guarde e confirme a notificação de sucesso.
4. Volte a abrir a conta para verificar a seleção guardada.

O Studio usa uma lista de seleção única, não caixas de seleção. Escolher outra função substitui a seleção. Para reunir várias permissões, configure uma função adequada e atribua essa função.

Editar a conta exige permissão para gerir utilizadores. A atribuição também exige permissão para gerir funções. Um erro na atribuição mantém o editor aberto; resolva-o antes de considerar a alteração concluída.

## Escolher as permissões

Escolha a função que concede apenas as permissões necessárias ao trabalho da pessoa. Alterar uma função partilhada muda as permissões de todos os seus membros. Consulte o número de membros antes de alterar as permissões.

Se não houver funções disponíveis, crie uma em **Definições → Funções** e volte a abrir o editor da conta.
