# Concepteur de rapports

Le modèle définit la mise en page du document. Le rapport de la bibliothèque relie ce modèle à une requête principale.

![Modèle ouvert dans le concepteur](report-designer-canvas.png)

## Deux actions distinctes

| Action du menu ⋯ | Résultat |
| --- | --- |
| **Publier une révision** | Publie une version du modèle enregistré. Ne crée pas de rapport dans la bibliothèque. |
| **Créer un rapport à partir de ce modèle** | Ouvre le formulaire de création d'un rapport lié au modèle et à une requête. Ne publie pas de révision du modèle. |

## Du modèle au rapport

1. Préparez une [requête enregistrée](/docs/query) et liez un tableau du modèle à cette requête.
2. Enregistrez le modèle et attendez la confirmation de sauvegarde. Les deux actions nécessitent un modèle déjà enregistré.
3. Dans le menu **⋯** du concepteur, choisissez **Publier une révision**. Vérifiez la confirmation contenant le nom du modèle et son statut publié.
4. Choisissez **⋯ → Créer un rapport à partir de ce modèle**.
5. Renseignez le **Nom** et la **Catégorie** du rapport. La **Description** est facultative. Vérifiez le **Modèle** et la **Requête principale**. La requête peut être présélectionnée depuis le premier tableau lié.
6. Dans le menu **⋯** du formulaire, choisissez **Créer le rapport**. Le nom, la catégorie, le modèle et la requête principale sont obligatoires.
7. Vérifiez la confirmation contenant le nom du nouveau rapport. Ce nom peut différer de celui du modèle.
8. Ouvrez [Rapports](/docs/reports), sélectionnez le rapport dans sa catégorie, renseignez les paramètres requis et lancez-le. Vérifiez le document et les lignes du tableur.

Par exemple, utilisez une requête enregistrée qui renvoie deux colonnes. Liez un tableau à cette requête, enregistrez le modèle et publiez sa révision. Créez ensuite un rapport portant un nom distinct, avec cette requête principale. Vérifiez sa présence dans la bibliothèque et les colonnes obtenues.

## Vérifier le résultat

Une révision publiée appartient au modèle. L'entrée créée dans Rapports porte le nom choisi pour le rapport. La requête principale fournit les lignes du tableur ; le modèle définit la mise en page du document.

Pour publier une révision ultérieure du même modèle, il n'est pas nécessaire de créer un autre rapport. Utilisez l'action de création uniquement pour ajouter une entrée à la bibliothèque.

Si la création est désactivée, vérifiez les quatre champs obligatoires. Si le modèle est publié mais absent de Rapports, utilisez l'action de création du rapport.
