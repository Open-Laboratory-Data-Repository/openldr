# Rôles

Un rôle regroupe des permissions, par exemple consulter des rapports ou modifier des workflows. Dans **Paramètres → Rôles**, vous pouvez examiner les permissions et le nombre de membres de chaque rôle.

## Attribuer un rôle à un utilisateur

L'attribution se fait dans **Utilisateurs**, sur le compte concerné.

1. Ouvrez le menu **⋯** du compte et choisissez **Modifier**.
2. Attendez le chargement de **Rôle**, puis sélectionnez un seul rôle.
3. Enregistrez et vérifiez la notification de réussite.
4. Rouvrez le compte pour vérifier la sélection enregistrée.

Studio utilise une liste à choix unique, pas des cases à cocher. Choisir un autre rôle remplace la sélection. Pour regrouper plusieurs permissions, configurez un rôle adapté, puis attribuez ce rôle.

La modification du compte nécessite la permission de gérer les utilisateurs. L'attribution nécessite aussi la permission de gérer les rôles. Une erreur d'attribution laisse l'éditeur ouvert ; corrigez-la avant de considérer la modification comme terminée.

## Choisir les permissions

Choisissez le rôle qui accorde uniquement les permissions nécessaires au travail de la personne. Modifier un rôle partagé change les permissions de tous ses membres. Consultez le nombre de membres avant de modifier ses permissions.

Si aucun rôle n'est disponible, créez-en un dans **Paramètres → Rôles**, puis rouvrez l'éditeur du compte.
