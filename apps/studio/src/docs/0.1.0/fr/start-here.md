# Commencer ici

## Objectif

Repérez Tableau de bord, Rapports et Documentation. Ouvrez les paramètres d'un rapport et trouvez Exécuter.
Les images numérotées montrent l'interface anglaise avec des exemples fictifs, sans données de patients.

## Avant de commencer

Connectez-vous à Studio. Les pages visibles dépendent de vos permissions.
Sur téléphone, ouvrez d'abord le menu de navigation. Sélectionnez une image pour l'agrandir.

## Étapes

![Navigation : 1 Tableau de bord, 2 Rapports, 3 Documentation. Établissements est aussi visible.](start-here-navigation.png)

1. Ouvrez **Tableau de bord** pour consulter les tableaux partagés avec votre compte.
2. Ouvrez **Rapports** pour consulter la bibliothèque.
3. Ouvrez **Documentation** et cherchez une tâche dans la recherche. Revenez ici après avoir consulté un guide.

La navigation comprend aussi **Établissements** si votre compte peut les consulter.
Demandez à votre administrateur les permissions nécessaires pour une page absente.

![Menu du rapport : 4 Parameters, les paramètres](start-here-report-menu.png)

4. Revenez aux **Rapports**, sélectionnez un rapport et ouvrez son menu **⋯**. Choisissez **Paramètres**.

![Paramètres : 5 champ d'exemple, 6 Run, exécuter](start-here-parameters.png)

5. Renseignez les paramètres obligatoires. Chaque rapport définit ses champs. Cet exemple utilise un champ texte.
6. Sélectionnez **Exécuter** quand les valeurs obligatoires sont complètes. Le rapport utilise ces valeurs.

La capture s'arrête avant l'exécution. Le résultat dépend du rapport et des données disponibles.
Retrouvez le [guide Rapports](/docs/reports) dans la documentation.
Les liens des guides associés, précédent et suivant permettent de poursuivre la lecture.

## Résultat attendu

Vous savez trouver ces pages, chercher dans le manuel et ouvrir les paramètres d'un rapport.

## Dépannage

- Une page manque. Demandez à un administrateur de vérifier vos permissions.
- Exécuter est désactivé. Renseignez chaque paramètre obligatoire.
- Une image est trop petite. Sélectionnez-la pour l'agrandir. Le texte numéroté explique aussi chaque action.
- La recherche retourne trop de résultats. Cherchez la tâche ou le message d'erreur exact.

## Filtrer les tableaux

Selon la page, la barre propose recherche, filtres, tri et choix des colonnes.
La recherche suit votre saisie. Ajoutez un filtre avec une colonne, un opérateur et une valeur, puis appliquez-le.
Supprimez une règle avec sa pastille ou effacez tous les filtres.
